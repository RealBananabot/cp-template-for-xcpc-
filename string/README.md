# 字符串模板

这些 `.cpp` 都是粘贴片段。先使用上一层的 [s.cpp](../s.cpp) 缺省源，再按下表添加需要的代码；编译选项为 `-std=gnu++20 -O2`。数组、字符串位置及排名均从 0 开始；自动机节点编号单独约定。模板不在热路径检查非法下标或容量。

现场使用 Runs 时，选择 [runs_hash.cpp](runs_hash.cpp) 或 [sa.cpp](sa.cpp) + [runs_sa.cpp](runs_sa.cpp)。两份直接函数的签名相同，不可同时粘贴；封装版保留供复用 LCP/LCS 查询。

**已知正确性限制：固定单模哈希有实际错误反例。** `lcp_hash.cpp`、`runs_hash.cpp` 以及 `runs.cpp` 搭配 `hash_lcp` 都受影响。需要确定性结果时使用 SA 版；反例及原版、优化版的历史性能见 [runs_notes.md](runs_notes.md)。其余实现本次复查未发现新的正确性错误，仍须遵守各项前置条件。

## 接口与复杂度

`n` 为当前串或序列长度，`m` 为另一串长度，`L` 为多个输入串的总长度（包含重复前缀），`V` 为实际节点数，`S` 为字符集大小，`C` 为构造器的容量参数。自动机的 `fa/len/dep` 按容量初始化，构造时额外花费 O(C) 时间；表中的构建时间按容量与实际处理规模同阶计算。空间包含返回数组，不包含调用者已有的输入。

| 文件 | 接口与返回值 | 时间 | 空间 |
|---|---|---|---|
| [gsam.cpp](gsam.cpp) | `SAM(C)`；`ins(p,c)`；`solve()` 返回 `{不同非空子串数, 含根状态数}` | 固定 S 构建 O(L)，`solve` O(V) | O(SC) |
| [ac.cpp](ac.cpp) | `AC(C)`；`ins(p,c)`；`build()` 补齐转移表 | 插入 O(L)，构建 O(SV)，扫描文本 O(m)，另计统计工作 | O(SC) |
| [pam.cpp](pam.cpp) | `PAM(C)`；`ins(u,pos)`；保留 `str/fa/len/dep` | 固定 S 构建 O(n) | O(SC) |
| [sa.cpp](sa.cpp) | `SA(s)` 返回 `{rk,sa}`；`get_height(s,sa,rk)` 返回相邻后缀 LCP | SA O(n log n)，height O(n) | O(n) |
| [lyndon.cpp](lyndon.cpp) | `lyndon(s)` 返回边界 `{0,...,n}`，各段为左闭右开区间 | O(n) | 返回 O(分段数 + 1)，辅助 O(1) |
| [kmp.cpp](kmp.cpp) | `kmp(s)` 返回 `fail`，记录最长真 border 的末下标 | O(n) | O(n) |
| [z.cpp](z.cpp) | `zfunc(s)`；`exkmp(s,t)` 中 s 为文本、t 为模式 | O(n)；O(n+m) | O(n)；O(n+m) |
| [manacher.cpp](manacher.cpp) | `manacher(s)` 返回插入分隔符后的各中心半径 | O(n) | O(n) |
| [min_rotation.cpp](min_rotation.cpp) | `min_rotation(a)` 返回最小循环表示的最早起点 | O(n) | O(1) |
| [lcp_hash.cpp](lcp_hash.cpp) | `hash_lcp(s)`，支持 `val/lcp/lcs/cmp`，有碰撞风险 | 预处理 O(n)，val O(1)，其余 O(log n) | O(n) |
| [lcp_sa.cpp](lcp_sa.cpp) | 接在 `sa.cpp` 后，`sa_lcp(s)` 支持 `lcp/lcs/cmp` | 预处理 O(n log n)，查询 O(1) | O(n log n) |
| [runs_hash.cpp](runs_hash.cpp) | `get_runs(s)` 返回排序去重的 `{l,r,p}`，有碰撞风险 | O(n log n) | O(n) |
| [runs_sa.cpp](runs_sa.cpp) | 接在 `sa.cpp` 后，接口与哈希版相同 | O(n log n) | O(n log n) |
| [runs.cpp](runs.cpp) | 封装版：`get_runs<T>(s)` 或 `get_runs(s,t)` | 枚举 O(nQ+n log n)，另计预处理；提供的实现总时间均为 O(n log n) | 枚举 O(n)，另计查询结构 |

`Q` 是单次后缀比较、LCP 或 LCS 查询的最大代价。所有 Runs 结果中 `[l,r]` 为 **闭区间**，`p` 为最小周期，并满足长度至少为 `2p`；按题目要求输出时，仅给 l、r 加 1。

## 节点、数组与边界约定

- GSAM、AC 的根均为 1。GSAM 的 `fa[1]=0`；每个新串从根开始，依次处理完该串。`C` 按逐串插入的总字符数计，包含公共前缀和重复串，不能据此按 Trie 节点数估算这份实现的复杂度。支持空集合、空串和重复串。
- AC 在建完所有模式串后只调用一次 `build()`，之后不能继续插入或重新构建。`fa[1]=0`，节点 0 是转移哨兵。重复模式串终点相同，模式串要求非空；支持无模式串及空文本。不附带 topo、出现次数汇总或逐个匹配输出，沿 fa 枚举匹配时应另计遍历代价。
- PAM 的 1 号偶根长度为 0，2 号奇根长度为 −1，`fa[1]=fa[2]=2`，两根 `dep=0`。非根 `dep[u]=dep[fa[u]]+1`，表示非空回文后缀数。初始 u=1，按位置 0、1、… 调用 `u=ins(u,pos)`；pos 必须已存在于 `str` 中。可以预先存串或逐字追加，已处理的前缀不能改变。枚举非空回文后缀时以 `u>2` 为继续条件，避免奇根自环。P5496 的当前字符须在调用 `ins` 前解密。
- GSAM、AC 的字符参数为 `[0,S)` 中的编号；默认 S=26。PAM 内部使用 `'a'..'z'`。其余字符串算法按字节处理；需要排序时按无符号字节比较，不进行 Unicode 码点解码。最小表示的输入为 `vi`，允许任意 int 值。
- `rk`、`sa` 互为逆排列。`height[0]=0`，`height[r]=lcp(s[sa[r-1]..],s[sa[r]..])`；`get_height` 必须使用同一字符串的 SA 结果。
- `fail[i]` 是最长真 border 的末下标，没有 border 时为 −1，border 长度为 `fail[i]+1`。
- `z[0]=n`。`exkmp(s,t)[i]=lcp(t,s[i..])`，空模式得到全 0 数组。
- Manacher 使用 `?s[0]?s[1]?...?`，半径不含中心。原串对应区间为 `[(i-d[i])/2,(i+d[i])/2)`，最长回文长度为 `max(d)`。原串中允许出现 `?`，因为每次比较的两个位置奇偶性相同。
- 最小表示采用 Duval 算法；多个起点对应相同最小序列时返回最小下标。已经用条件减法代替变量取模，不复制输入数组；千万规模的历史对比见 [min_rotation_notes.md](min_rotation_notes.md)。
- 空输入返回：`SA` 的两数组、height、KMP、Z、exKMP 文本数组以及 Runs 返回空数组；Lyndon 返回 `{0}`，Manacher 返回 `{0}`，最小表示返回 −1。空串可构造 LCP 查询对象，但没有合法查询下标。
- LCP/LCS/后缀比较的查询下标必须在 `[0,n)`；LCS 包含给定的两个结束位置。`val(l,r)` 使用左闭右开区间，须满足 `0<=l<=r<=n`。`hash_lcp` 保存输入引用，输入必须持续存活且不变；`sa_lcp` 保存构造时的快照。传给 `get_runs(s,t)` 的 t 必须对应同一个 s。

长度通常须能用 int 表示，另有以下算术限制，均还需要实际内存足够：

| 模板 | 附加限制 |
|---|---|
| GSAM | `0 <= C <= (INT_MAX-2)/2` |
| AC | `0 <= C <= INT_MAX-2` |
| PAM | `0 <= C <= INT_MAX-3` |
| 哈希 LCP、直接哈希 Runs | `n < INT_MAX` |
| Manacher | `n <= (INT_MAX-1)/2` |
| 最小表示 | `n <= INT_MAX/2` |

SA LCP/LCS 和直接 SA Runs 使用两份稀疏表：n=1,000,000 时，仅表内 int 元素合计约 145 MiB，另有排名和临时空间；应按 O(n log n) 空间预算。

## 复杂度复核要点

- KMP 的失配跳转、Z/exKMP 的右边界推进、Manacher 的右边界扩展均按总进度均摊，不能把嵌套循环直接看成平方。
- SA 每轮计数排序与重排为 O(n)，倍增至覆盖整个后缀需要 O(log n) 轮；height 中维护的 k 在外层每步至多减 1，总扩展 O(n)。
- Duval 每轮跳过完整因子及其重复，线性扫描；最小表示在虚拟双倍序列上执行同一过程，只记录第一份中的候选。j、k 始终小于 2n，减法回绕等价于取模。
- GSAM 按上述逐串顺序构建，`ins` 的跳转需均摊分析，单次并非最坏 O(1)；每次最多创建两个状态，复制或初始化转移表另计 O(S)。PAM 每次最多创建一个回文节点，后缀跳转总计线性。两者均不应按一次 `ins` 恒定时间理解。
- AC 每个 Trie 节点入队一次，每次处理 S 个字符。建表后扫描文本每字符一次转移；输出所有匹配或汇总出现次数另计。
- Runs 两次单调栈扫描中每个位置至多入栈、出栈各一次，共 O(n) 次查询和候选；最终排序去重 O(n log n)。SA 查询用两份 O(n log n) 稀疏表换取 O(1) 查询；哈希二分每次 O(log n)，固定哈希碰撞会破坏正确性。

