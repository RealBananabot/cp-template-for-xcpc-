# 最小循环表示：取模效率测试

测试日期：2026-11-04。AMD Ryzen 7 H 260；GCC 15.2.0；`g++ -std=gnu++20 -O2`，未加 `-march=native`。

每组 10,000,000 个 int 元素，固定单个逻辑核运行；每种方案启动 5 个独立进程，交错测试并取耗时中位数。计时仅包含函数调用，不含数据生成和输入输出；复制数组版包含临时数组的分配、两次复制和释放。内存为整个进程的峰值 RSS，包含原始输入数组。

三版均使用相同的 Duval 算法：

- 取模版：原 `min_rotation.cpp`，通过 `a[j % n]`、`a[k % n]` 访问。
- 减法回绕版：当前实现，利用 `0 <= j, k < 2n`，通过 `(j < n ? j : j - n)` 等访问，保持 O(1) 辅助空间。
- 复制数组版：临时建立长度 2n 的序列，再直接访问下标。

| 数据 | 取模 / ms | 减法回绕 / ms | 复制数组 / ms | 取模耗时 / 回绕耗时 |
|---|---:|---:|---:|---:|
| 26 元字母表随机 | 75.8 | 40.3 | 66.9 | 1.88 |
| 二元随机 | 75.9 | 40.2 | 67.2 | 1.89 |
| 全范围 int 随机 | 75.8 | 40.3 | 67.2 | 1.88 |
| 全相等 | 80.1 | 44.3 | 71.5 | 1.81 |
| 周期 26 | 76.2 | 40.5 | 67.9 | 1.88 |
| 严格递增 | 75.8 | 40.2 | 67.4 | 1.89 |
| 严格递减 | 62.1 | 29.9 | 58.3 | 2.07 |
| Thue–Morse | 91.8 | 48.8 | 74.4 | 1.88 |
| 前 n−1 项为 1、末项为 0 | 77.8 | 42.4 | 69.6 | 1.84 |

三种方案在全部 135 次大规模运行中的返回下标一致。取模版及减法回绕版峰值 RSS 约 41.7–41.8 MiB；复制数组版约 118.1 MiB，额外数组的理论空间约 76.3 MiB。

本次编译结果中，原版内层循环仍有两条 `idiv` 指令，变量取模没有被消除。减法回绕版耗时约为原版的 48%–55%，保持线性时间和常数辅助空间。具体比值受 CPU、编译器及数据影响。

正确性：三版共同通过 98,573 组小规模穷举、随机序列与朴素枚举所有旋转起点的对拍，检查了相同最小表示时返回最小下标；通过 ASan/UBSan 检查。输入可包含任意 int，空序列返回 −1，长度须不超过 INT_MAX / 2。
